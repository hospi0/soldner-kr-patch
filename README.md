## 번역 원문 (`work/text/*.tsv`, 열: 번호 · 바이트/예산 · JP · KO)
| 파일 | 내용 | 비고 |
|---|---|---|
| `msg.tsv` | 대사(MESSAGE.DAT, 번호 = 블록:문장) | 길이 자유. `{xx}` = 제어 바이트(그대로 둘 것), `\n` = 줄바꿈 |
| `exe.tsv` | 실행 파일 메뉴·아이템·설명 | 예산 = 원문 바이트(제자리). `{1b}{43}{36}`=색, `%s`·`%2d` 등 printf 유지 |
| `kana.tsv` | 반각 가타카나 이름(직업·몬스터·마법) | 예산 = 원문 바이트(반각 1 B/자) |
| `job.tsv` · `bevent.tsv` · `scenario.tsv` | 의뢰 설명·전투 이벤트·시나리오 표 | 형식 해독 전 — 제자리 예산 |

### 대사 제어 표기 (`tools/msgcode.py`, 20,247문장 전부 무손실 왕복 확인)
| 표기 | 뜻 |
|---|---|
| `{z}` | 문장 머리 |
| `{g}` `{u}` | 입력 대기·끝 |
| `{w}` | 대기 |
| `{f}` `{l:00xx}` | 얼굴 |
| `{s:xxxx}` | 이름표(«§ 이름 §») |
| `{v:xxxx}` | 음성 번호 |
| `{c:05}`/`{c:07}` | 글자색 강조/보통 |
| `{b:xx}` | 숫자 끼워 넣기(«{b:00}Ｇ» = 금액) |
| `{j:xxxx}` | 다음 문장으로 이동 |
| `{y:00xxxxyyyy}` | 예/아니요 선택(이동할 문장 번호 2개) |
| `{o}` `{d}` `{a:xxxx}` `{p:xx}` | 기타 제어 |
| `{00}` | 문장 끝 NUL |
★제어 표기는 **순서·개수 그대로** 두고 글만 번역한다. 대사창은 2바이트 글자만 — 반각 영숫자·공백은 빌더가 전각으로 바꾼다.
