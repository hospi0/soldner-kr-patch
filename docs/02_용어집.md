# 번역 용어집 · 표기 원칙

번역 칸 표기와 도구는 `tools/tr.py` 머리말 참고. 새 이름이 나오면 여기에 먼저 적고 쓴다.

## 표기 원칙

- 제어 표기(`{z}{s:0320}`…, README)는 순서·개수 그대로. `tools/tr.py` 로 넣을 땐 이어진 제어 묶음을 ①②… 로 줄여 쓰면 원래 표기로 펼쳐 준다.
- 이름 끼움 `{a:0000}`(주인공) 등 뒤에는 받침에 따라 바뀌는 조사를 붙이지 않는다 → «님·의·에게·도·여» 로 받거나 문장을 바꾼다.
- 대사창은 2바이트 글자만: 반각 공백·?!·숫자는 빌더가 전각으로 바꾼다.
- 쉼표(，)는 글꼴에 있는지 미확인 → 쉼표 자리는 띄어쓰기·줄바꿈으로 대신한다. 문장 끝 마침표는 서술문(엔딩)에만 «.»(→ ．, 역시 미확인).
- 엔딩 서술(`{z}` 없는 12자 조각 여러 개)은 조각마다 12자 이하, 조각 수는 그대로. 낱말 사이에서 끊는다.
- 말투: 원문 반말/존댓말을 그대로. 노인 «〜じゃ» → «〜라네/〜구먼», 무사풍 «それがし» → «소인/본인».
- 대사 한 줄은 원문 가장 긴 줄 또는 22자 이하(대사창 폭 미확인 — 실기 확인 필요).

## 이름 끼움 번호 `{a:xxxx}` ↔ 인물 (대사 문맥으로 확인)

`tools/tr.py` 의 `ANAME` 과 같다. 여기 있는 인물은 이름이 고정이므로 받침에 맞는 조사를 바로 붙여도 된다(검사기가 확인).
**EXE 인물 표(이름표·이름 끼움 원본)도 반드시 이 이름으로 번역할 것.** 0000(주인공)은 플레이어가 바꾸므로 조사를 붙이지 않는다.
