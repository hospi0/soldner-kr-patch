  `n`=줄바꿈 · `g`=입력 대기 · `c xx`=글자색(05 강조·07 보통) · `j 00 xx`=분기/점프(인수 2 B 추정) · `v xx`·`w xx`=인물 소개 표(값 목록).

  색 전환은 `ESC C 6`/`ESC C 7`, 값은 printf(`%s` `%2s` `%7lu`).
